# Tests de fumée V1.0

Après un verdict SQL conforme et avant décision finale :

- [ ] Connexion Administrateur puis non-administrateur; restrictions conformes.
- [ ] Navigation principale sans erreur console bloquante.
- [ ] Infrastructure, fiche 360 et intégrité de `support_id`.
- [ ] Campagnes, EDT, bons de travail.
- [ ] Photos : consultation, ajout/remplacement contrôlé et suppression vérifiée sans perte inattendue.
- [ ] Terrain, enjeux, inspections et centres d’information.
- [ ] Studio des relations : consultation et autorité de `relation_rules` préservée.
- [ ] Gestionnaire des champs : consultation, sauvegarde isolée d’un brouillon, `no_change`, `stale_draft`, aucun effet métier et aucune activation.
- [ ] Imports et exports existants inchangés.
- [ ] Invitation de test vers le domaine public autorisé.
- [ ] Aucun lien vers une adresse de boucle locale.
- [ ] Responsive minimal : bureau, tablette et mobile; navigation clavier essentielle.

Tout échec bloquant impose l’arrêt et le plan de retour arrière.
